DudeBooru — приложение, которым удобно пользоваться с телефона: лента во всю ширину
с папкой для каждого источника, просмотр жестами, а лайки, сохранённое и загрузки хранятся на устройстве.
Без рекламы, аналитики и Google Play Services.

## Возможности

**Лента**
- Каждый источник — в своей папке: переключение свайпом, порядок и видимость настраиваются, видно, сколько новых постов с прошлого захода.
- Сортировка: новые, горячее, лучшее, по избранному, популярное за день, неделю, месяц или год, самые крупные, альбомные, портретные и случайные.
- Поиск по тегам с подсказками. Если бесплатный аккаунт ограничивает число тегов, DudeBooru сам раскладывает запрос:
  сортировка и самые редкие теги уходят на сайт, остальные проверяются на устройстве.
- Родительские и дочерние посты собираются в карусели.
- Негативные теги для одного источника или для всех; скрытые посты можно посчитать и показать.

**Просмотр**
- Масштаб щипком и двойным касанием, огромные картинки декодируются тайлами; оригинал подгружается при увеличении.
- Плеер видео: полоса прогресса с перемоткой, пауза и звук. Включили звук — музыка в других приложениях встаёт на паузу.
- Видео и GIF отмечены по-разному — и в ленте, и в сетке.
- Свайп вниз закрывает, вверх — детали; на остальных экранах свайп вправо возвращает назад.

**Контент и безопасность**
- Три режима: безопасный, NSFW и всё — откровенное открывается только после подтверждения возраста 18+.
- Цензура спойлером, размытием или пикселями с настраиваемой силой — в ленте и в просмотре.

**Коллекции**
- Лайки, сохранённое с папками, история просмотров и загрузки.
- Загрузка в облегчённом или оригинальном качестве, с шаблоном имени файла и тегами в метаданных XMP.
- По желанию — синхронизация лайков и избранного с аккаунтом на сайте.

**Рекомендации**
- Профиль вкуса строится на устройстве по лайкнутому и сохранённому — только из тегов, которые повторяются.
- У каждой рекомендации есть причина; «Найти похожие» работает для любого поста.

**Уведомления**
- Подписки на художников и уведомления о новых работах (проверка раз в 6 часов); колокольчик выключает уведомления у одного художника.
- Уведомления о новых версиях: загрузка прямо в приложении с проверкой подписи.

**Оформление**
- Готовые темы — Monet (цвета обоев), Классическая, AMOLED, Miku, Тето, Maid и Sakura — и редактор своей.
- Темы можно передавать файлом или коротким кодом; любой пост можно поставить фоном ленты.
- Автоматическая ночная тема по расписанию или по закату.
- Альтернативные иконки приложения, в том числе нейтральная.
- Интерфейс на русском и английском.

## Установка

1. Скачайте последний `DudeBooru-x.y.z.apk` из [Releases](../../releases).
2. Откройте его на телефоне и разрешите установку из этого источника, когда Android спросит.

Нужен Android 8.0 или новее. Обновления проверяются в **Настройки → О приложении** и ставятся поверх
текущей версии.

Все выпуски подписаны одним ключом. Чтобы проверить APK, сравните отпечаток сертификата:

```
apksigner verify --print-certs DudeBooru-x.y.z.apk
```

```
SHA-256: 97c4df13bdc40fe0ba8211e0ea7f9addb5cf9004aa0377b501ded4c23451df58
```

Открытая часть сертификата — [`.github/release/signing-cert.pem`](.github/release/signing-cert.pem).

## Приватность

- Всё хранится на устройстве: лайки, история, загрузки и профиль вкуса. Своего сервера у DudeBooru нет.
- Приложение обращается только к сайтам, которыми вы пользуетесь, и — для проверки обновлений — к GitHub.
- API-ключи и пароли зашифрованы в Android Keystore.
- По желанию — блокировка отпечатком, лицом или PIN-кодом телефона и запрет скриншотов.
- DNS-over-HTTPS (Cloudflare, Google, Quad9, AdGuard) и свой прокси — для сетей, где сайты заблокированы.

## Сборка из исходников

Нужны JDK 21 и Android SDK (platform 37).

```
./gradlew :app:assembleDebug     # debug APK
./gradlew :booru:test            # модульные тесты
```

Тесты против живых сайтов по умолчанию пропускаются:

```
./gradlew :booru:test -Plive --tests '*LiveApiTest*'
```

Если сайты не открываются напрямую, тесты берут прокси из `HTTPS_PROXY`.

Сборка без проверки обновлений (для F-Droid и похожих каталогов):

```
./gradlew :app:assembleRelease -PnoUpdateCheck
```

## Выпуски

GitHub Actions собирает и тестирует каждый пуш (`CI`, debug APK — в артефактах). Коммит с `[release]`
в сообщении собирает версию из `app/build.gradle.kts`; заметки к выпуску — в
`.github/release/notes/<версия>.md`.

Подписать выпуск можно двумя способами:

- **С секретом `DUDEBOORU_SIGNING_KEY`** (закрытый ключ P-256 в hex или PEM) выпуск подписывается и публикуется сразу.
- **Без секрета** ключ не покидает владельца. Сборка печатает хеш содержимого APK; владелец подписывает его
  (`python3 .github/scripts/apk_v2.py signed-data <хеш> .github/release/signing-cert.pem data.bin`,
  затем `openssl dgst -sha256 -sign key.pem -out sig.der data.bin`), кладёт
  `.github/release/signatures/<версия>.json` с полями `version`, `run_id`, `commit` и `signature` (hex)
  и пушит коммит с `[publish]`.

Для локальной подписанной сборки положите `keystore.properties` в корень проекта (в git он не попадает):

```
storeFile=release.p12
storePassword=…
keyAlias=dudebooru
keyPassword=…
```

## Отказ от ответственности

DudeBooru — независимый клиент, он не связан с Danbooru, Safebooru, Yande.re и Konachan и не одобрен ими.
Картинки и теги принадлежат авторам и сайтам. Часть контента на этих сайтах предназначена только
для взрослых; откровенное скрыто, пока вы не подтвердите, что вам есть 18.
